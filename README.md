# LineUp

LineUp compares a vendor's quote with its invoices, line by line, so you can see what matches and what does not.

## Install it (Windows)

1. **[Download LineUp-Setup.exe](https://github.com/aburchard-dev/LineUp-updates/releases/latest/download/LineUp-Setup.exe)** (about 100 MB).
2. Double-click it. You do not need administrator rights, Python or anything else.
3. Windows may show a blue "Windows protected your PC" box because the installer is not code-signed. Click **More info**, then **Run anyway**.
4. Leave "Put a LineUp icon on my desktop" ticked and click through. LineUp opens when it is done.

## Updates

LineUp checks for a newer version every time it opens. If there is one, it downloads, checks and installs it by itself, then reopens. Your saved sessions are kept. If you are offline, it simply opens as it is.

## Getting help

Use the **Issue or suggestion?** link in the bottom-left corner of the app.
